LE LONGCHAMP RESTAURANT WEBSITE

Open index.html in a browser to preview. No build tools or installation are required.

Features:
- Responsive restaurant landing page with supplied restaurant/food photos
- Menu items entered as editable text/data (menu screenshots are not displayed)
- Category filters and Add buttons
- Cart quantity controls and subtotal
- WhatsApp order draft to +253 77 10 49 49
- Directions link, click-to-call, gallery and restaurant information

To edit menu items, update the `items` array in script.js. Prices are shown in DJF.
To change the WhatsApp number, edit the wa.me URL in script.js.
